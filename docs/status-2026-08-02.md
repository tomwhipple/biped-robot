## What shipped today

### C2 command shaping + goal-speed streaming (`9fac272`)

The act path used to write raw 50 Hz targets with goal speed 0 (=
unlimited): every tick was a max-speed slam-and-stop — a velocity square
wave on every joint, i.e. the jerk. Now:

- **`obs::CommandShaper`** — three cascaded exact first-order lags, poles at
  **10 Hz**, on the policy targets. The commanded trajectory is C2:
  continuous velocity *and* acceleration, finite jerk. Reseeds from measured
  q on every torque (re)engage. `prev_action` stays the raw policy output.
- **Per-servo goal speed** (reg 46) in every SYNC WRITE: closes the measured
  gap in one tick ×1.25 headroom, floor 50, cap 3400. Trajectory-speed while
  tracking; disturbances grow it back to max, so no stiffness lost.
- Pole picked by **closed-loop referee sweep** through the SIL stack
  (loco_v8foot, 8 seeds): stand/line 8/8 at all poles; goal_home python 7/8
  vs raw 5/8, 16 Hz 7/8, 10 Hz 6/8, **8 Hz 4/8 (rejected — too much lag)**.
- Live-tunable: CLI `shape [hz]`, 0 = off. SIL twin: `sil_set_shaper()`,
  `SilTargets.goal_speed` (sil_abi 2). The pytest gate scores the referee
  against the shaped plant.
- Also fixed: host Makefile now lists component headers as prerequisites —
  a stale `libctrl_sil.dylib` had turned the gate green against an old pole.

## Incident: feet broken during `pose` verification

A `pose 2048 ×10` was sent as a "motion-free" check with torque off. Two
false assumptions compounded: STS servos **auto-enable torque on a goal
write**, and raw 2048 is not this robot's neutral (ankle zeros are
3516/3450, so 2048 ≈ −129° — toes-up through the hard stop). Both printed
feet broke off; servos survived with no fault flags. Feet reprinted and
fitted same day.

### Guards added so one wrong assumption can't do that again (`5981a71`…`c914e5f`)

- **torqueGate** — `move`/`pose` refuse any goal write while torque reads
  off or unreadable. Motion is an explicit two-step: `torque`, then move.
  (Verified live: with servo power off, `move` refuses.)
- **Calibrated range clamp** — bench targets for policy servos clamp to the
  joint's mechanical range through the calibration, not encoder 0..4095.
- **Cal blob v2** is bound to the servo map it was measured under; `run`
  refuses without a valid NVS calibration.
- **Automatic v1→v2 migration** — the as-built table is compiled in
  (`firmware/main/asbuilt_cal.h`, paired with `servo-map.md`; re-zero ⇒
  update both in one commit). A v1 blob that exactly matches it migrates at
  boot with no operator step; anything else is refused. Verified on the
  board: first post-flash boot migrated, `cal show` matches the table.
