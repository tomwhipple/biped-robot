# Raspberry Pi 4 Model B: manufacturer documents

Raspberry Pi Ltd's mechanical drawings of the Pi 4B, mirrored verbatim from
its Product Information Portal
(<https://pip.raspberrypi.com/categories/545-raspberry-pi-4-model-b>),
retrieved 2026-10-24. Raspberry Pi publishes no 3D model of the Pi 4B.

| file | what it is | source |
|---|---|---|
| [RP-008343-DS-1-raspberry-pi-4-mechanical-drawing.pdf](RP-008343-DS-1-raspberry-pi-4-mechanical-drawing.pdf) | the mechanical drawing: 85 × 56 mm outline, holes Ø2.7 on 58 × 49 mm, connector positions | [pip-assets.raspberrypi.com](https://pip-assets.raspberrypi.com/categories/545-raspberry-pi-4-model-b/documents/RP-008343-DS-1-raspberry-pi-4-mechanical-drawing.pdf) (the portal's RP-001185 is the same file, byte for byte) |
| [RP-008342-DS-1-raspberry-pi-4-mechanical-drawing.dxf](RP-008342-DS-1-raspberry-pi-4-mechanical-drawing.dxf) | the same drawing as DXF | [pip-assets.raspberrypi.com](https://pip-assets.raspberrypi.com/categories/545-raspberry-pi-4-model-b/documents/RP-008342-DS-1-raspberry-pi-4-mechanical-drawing.dxf) |

A third-party STEP exists (SolidWorks 2018, 2019-07-22, in a fork of a KiCad
library for the Pi; no author or licence stated):
<https://code.c-base.org/wercc/monorail-pcb/raw/branch/main/Libraries/Raspberry-Pi-4-library-for-kicad-master/Raspberry%20Pi%204%20Model%20B.STEP>.
It is not mirrored here; check it against the drawing before relying on it.
